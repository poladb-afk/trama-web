# Trama Textiles — web

Sitio estático de una sola página con las fotos del feed de Instagram.

- `index.html` es el sitio (se publica automáticamente en GitHub Pages en cada push).
- `img/` contiene las fotos que usa el sitio.
- Para reasignar fotos: tabla `ASIGNACION` en `mapear-fotos.py` (en el proyecto local), correr el script y volver a subir `img/`.
